# Reporting a security issue

Please report suspected vulnerabilities privately to [support@01splat.com](mailto:support@01splat.com), with **Security report** in the subject.

Include the affected 01Splat version, a description of the issue, its potential impact and minimal reproduction steps. Use sanitized examples. Do not include live passwords, tokens, license data or confidential captures.

Do not open a public issue or attach exploit material to this repository before the report has been reviewed. If additional sensitive details or files are needed, ask for a suitable private transfer method first.

Do not test against other users' accounts, projects or infrastructure without authorization. This reporting process does not grant permission for intrusive testing.
